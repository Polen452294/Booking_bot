root validator с cap_drop ALL не мог прочитать чужой 0700/0600 archive.

`booking-postgres` package текущей CLI version. Phase8 scan upstream обнаружил
22 HIGH/CRITICAL в gosu Go stdlib; hardened package дал 0. Tool image берётся
из source version, не из untrusted backup metadata.

restore и update qualification tests повторяются после fix.

## Known limitations

Один специалист на deployment; нет payments/deposits, CRM, AI, web admin/multi-master.
Conversations поддерживают text/photo/document; нет voice/video/group chat и edit/delete.
Media хранится как Telegram metadata/IDs. FSM drafts могут теряться.
Restore требует downtime; внешние Telegram messages не откатываются и exactly-once
delivery не гарантируется. Application update не заменяет storage images автоматически.
Windows/ARM64/Debian production support не заявлен; Ubuntu production gate ещё открыт.

**v1.0.0 не готов к установке первому реальному клиенту. BLOCKERS: B1–B4.**
